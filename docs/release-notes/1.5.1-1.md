## Что изменилось

- **Аппаратное декодирование Android:** H.264/HEVC через MediaCodec с выводом прямо в текстуру Flutter, без прежнего преобразования пикселей на CPU.
- **Управление очередями кадров:** ограниченные очереди и передача готовых изображений с учётом потребления текстуры.
- **Монитор качества:** активный программный/аппаратный путь, FPS и очереди. Подробное логирование включается отдельно.
- **Сборки:** Android ARM64 APK и macOS ARM64 DMG в одном релизе.

В коротком сравнении CPU Android-приложения снизился примерно с 91% до 21% одного ядра при близкой частоте кадров. Это не измерение времени работы от батареи.

### Установка

APK этого форка нельзя установить как обновление официального RustDesk из-за другой подписи. Сначала экспортируйте настройки. Этот выпуск ещё не содержит нативного захвата macOS и управления AWDL; они появятся в следующей версии.
