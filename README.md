# RustDesk — форк для macOS и Android

Неофициальный форк [RustDesk](https://github.com/rustdesk/rustdesk) с оптимизациями для управления Mac с Android.

**[Скачать сборки](https://github.com/rlshukhov/rustdesk/releases)** · [Изменения по версиям](docs/release-notes)

## Что изменено

- **Android:** аппаратное декодирование H.264/HEVC прямо в текстуру Flutter, без преобразования пикселей на CPU. Включается настройкой «Аппаратные кодеки».
- **macOS:** нативный захват ScreenCaptureKit и аппаратное кодирование VideoToolbox без прежних копирований кадров на CPU. Включается отдельно в настройках аппаратных кодеков.
- **Wi-Fi:** опциональная приостановка AWDL во время входящих сеансов убирает связанные с ним регулярные фризы. На это время AirDrop и Continuity недоступны; после сеанса AWDL восстанавливается.
- **Монитор качества:** путь декодирования, FPS и очереди кадров.

В коротких тестах при 3024×1964 нагрузка CPU приложения Android снизилась примерно с 91% до 21% одного ядра, Mac — с 45% до 10%, память хоста Mac — с 283 до 115 МиБ. Условия и FPS различались: это не измерение автономности. Нативный путь Mac сейчас даёт около 52 FPS; стабильные 60+ пока не достигнуты.

## Установка

В Releases доступны подписанные **Android ARM64 APK** и **macOS ARM64 DMG**. Подписи отличаются от официального RustDesk — перед переходом сохраните настройки. Обновления устанавливаются вручную; встроенное автообновление отключено.
